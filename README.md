# CrediFlow — Demo visual

Protótipo navegável de uma PWA para gestão de empréstimos pessoais, cobranças e carteira de clientes.

## Demo online

Após habilitar o GitHub Pages, a demo ficará disponível em:

`https://marqueskaio.github.io/empresta-demo/`

## O que está simulado

- Dashboard da carteira;
- Indicadores de carteira ativa, recebimentos e atrasos;
- Fluxo de cobranças que exigem atenção;
- Atividade recente;
- Modal de criação de empréstimo;
- Responsividade para desktop e celular;
- Manifesto básico de PWA.

Todos os dados são fictícios. Não há login real, banco de dados, movimentação financeira, cobrança ou integração de pagamentos.
